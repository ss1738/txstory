# Tasks (read aloud exactly; identical wording in both interfaces)

Before each task, give the participant the link from their session sheet. Read
the question, start the stopwatch, and stop it when they give a final answer. After
each answer, ask: "How confident are you, from 1 (guessing) to 5 (certain)?"

Amounts may be given as shown on the page; the participant does not need to
compute anything.

## T1: Simple transfer
- **Q1.** Did this transaction succeed?
- **Q2.** How much ETH was sent, and to which address? (The last four characters
  of the address are enough.)
- **Q3.** What fee was paid for this transaction, in ETH?

## T2: Exchange
- **Q1.** What did the sender give up, and what did they receive? Give the token
  names and amounts.
- **Q2.** Did the token the sender gave up leave their address in one transfer, or
  in more than one?
- **Q3.** Does the page say this transaction was a swap or exchange? If so, is that
  statement presented as a recorded fact or as an interpretation, and how can you
  tell?

## T3: Outcome
- **Q1.** Did the action this transaction requested actually happen?
- **Q2.** What did the sender lose because of this transaction?
- **Q3.** Were any tokens moved?

## T4: NFT
- **Q1.** Which NFT moved? Give the collection and the token ID.
- **Q2.** From which address to which address? (The last four characters are
  enough.)
- **Q3.** According to this page, did any payment change hands in this transaction?

## T5: Net result
- **Q1.** By exactly how much did the sender's ETH balance change because of this
  transaction?
- **Q2.** Does this page give you everything you need to state that number with
  certainty? If not, what is missing?
